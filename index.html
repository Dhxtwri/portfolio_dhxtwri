INDIVIDUAL PROJECT / LANGUAGE MODEL EDUCATION02

Perplexity Explorer

BIPOLAR-MODEL · Interactive language-model explainer

An educational browser application that visualizes how DistilGPT-2 assigns token probabilities and derives perplexity. Users can analyze a sentence, inspect token probabilities and next-token predictions, or use an offline manual simulator.

TECHNICAL APPROACH

Loads Xenova/distilgpt2 in-browser through Transformers.js, q8 quantized. Computes stable negative log probabilities and perplexity; selects top eight next-token candidates in one vocabulary pass.

IMPLEMENTATION

Single-page HTML/CSS and ES modules; no build step. Model download depends on network access; manual simulator works offline.

STACK

HTML · CSS · JavaScript ES modules · Transformers.js 3.8.1

INDIVIDUAL CONTRIBUTION

Repository owner and sole listed author; public repository currently contains README.md and index.html.
